# Как установить сервер RabbitMQ в Linux (краткое руководство)

Linux TLDR · Обновлено 16 июня 2025 · 4 мин

RabbitMQ — это бесплатная программа-брокер сообщений с открытым исходным кодом, используемая для обмена данными в реальном времени между пользователями в чат-приложениях, [поддерживающая протоколы](https://www.rabbitmq.com/docs/protocols) STOMP, MQTT, AMQP, HTTP, WebSocket и RabbitMQ Streams.

Её функциональность может напомнить вам [Apache Kafka](https://linuxtldr.com/installing-apache-kafka/), но разница в том, что RabbitMQ делает приоритетом сквозную доставку сообщений, тогда как Kafka — это платформа распределённой потоковой обработки событий, предназначенная для обмена в реальном времени непрерывными большими данными.

В этом руководстве вы узнаете, как установить и настроить сервер RabbitMQ в основных дистрибутивах Linux, создать учётную запись администратора, развернуть панель управления и получить к ней доступ через браузер.

## Как установить сервер RabbitMQ в Linux

Есть два способа установить сервер RabbitMQ в Linux: через стандартный менеджер пакетов (пакет есть в репозиториях большинства дистрибутивов Linux) либо с помощью зеркала Cloudsmith — стороннего репозитория, гарантирующего самую свежую версию.

Вы можете выбрать тот, который лучше всего подходит вам и вашей рабочей среде. Начинающим я советую начать со стандартного менеджера пакетов, так как это самый простой и понятный путь.

### Способ 1: установка сервера RabbitMQ через менеджер пакетов

Пакет сервера RabbitMQ доступен для нескольких популярных дистрибутивов Linux, таких как Debian, Ubuntu, Red Hat и Fedora. Пользователи этих систем могут напрямую установить стабильную версию с помощью стандартного менеджера пакетов своей системы.

```bash
# На Debian, Ubuntu, Linux Mint или Kali Linux
$ sudo apt install rabbitmq-server

# На Red Hat, Fedora, CentOS или AlmaLinux
$ sudo dnf install rabbitmq-server
```

### Способ 2: установка сервера RabbitMQ через зеркало Cloudsmith

Зеркало Cloudsmith — это сторонний репозиторий, официально предоставляемый RabbitMQ, чтобы доставлять пользователям самый свежий пакет сервера RabbitMQ раньше, чем он появится в репозиториях Linux.

Чтобы добавить зеркало Cloudsmith для пакета сервера RabbitMQ в Debian, Ubuntu, Linux Mint и других родственных дистрибутивах, выполните:

```bash
$ curl -1sLf 'https://dl.cloudsmith.io/public/rabbitmq/rabbitmq-erlang/setup.deb.sh' | sudo -E bash
```

Для Red Hat, Fedora, CentOS и других родственных дистрибутивов выполните:

```bash
$ curl -1sLf 'https://dl.cloudsmith.io/public/rabbitmq/rabbitmq-erlang/setup.rpm.sh' | sudo -E bash
```

После добавления репозитория можно устанавливать последнюю версию сервера RabbitMQ с помощью стандартного менеджера пакетов.

```bash
# На Debian, Ubuntu, Linux Mint или Kali Linux
$ sudo apt install rabbitmq-server

# На Red Hat, Fedora, CentOS или AlmaLinux
$ sudo dnf install rabbitmq-server
```

### Управление сервисом сервера RabbitMQ

Когда установка сервера RabbitMQ завершена, обязательно проверьте, что созданный при установке сервис RabbitMQ включён и активен, выполнив следующие команды:

```bash
$ systemctl is-enabled rabbitmq-server
$ systemctl status rabbitmq-server
```

Как видно, в моём случае он включён и активен. Если у вас это не так, обязательно включите и запустите сервис в фоне с помощью следующей команды:

```bash
$ sudo systemctl enable --now rabbitmq-server
```

### Устранение неполадок

Если при запуске сервисов вы столкнулись со сбоем сервиса, убедитесь, что стандартный порт **_5672_**, используемый сервером RabbitMQ, не занят другим сервисом, с помощью команды [`ss`](https://linuxtldr.com/ss-command/):

```bash
$ sudo ss -tulpn | grep 5672
```

В выводе выше процесс «_beam.smp_» управляется сервером RabbitMQ, так что проблема не в нём. Однако если порт использует другой пользователь или сервис, обязательно [закройте сервис по номеру порта](https://linuxtldr.com/installing-killport/) или по [имени сервиса](https://linuxtldr.com/kill-a-process-running-on-a-specific-port-in-linux/).

## Настройка сервера RabbitMQ

Чтобы настроить сервер RabbitMQ с именем хоста и сетевыми параметрами, нам нужно изменить параметры в файле «_rabbitmq-env.conf_». Этот конфигурационный файл используется для установки глобальных переменных окружения RabbitMQ, таких как имена узлов, расположения каталогов, флаги среды выполнения и т. д.

Наша главная мотивация для правки этого файла — настроить его с нашим именем хоста и внутренней сетью (НЕ ВЫСТАВЛЯЙТЕ ЕГО НА ПУБЛИЧНЫЕ IP-АДРЕСА). Для начала откройте файл в вашем любимом текстовом редакторе (я выбрал [Nano](https://linuxtldr.com/nano-editor/)).

```bash
$ sudo nano /etc/rabbitmq/rabbitmq-env.conf
```

Когда файл открыт, вы увидите следующие параметры, закомментированные префиксом «_#_»:

```text
#NODENAME=rabbit
#NODE_IP_ADDRESS=127.0.0.1
#NODE_PORT=5672
```

Чтобы настроить сервер с внутренней сетью, найдите ваше имя хоста и внутренний (локальный) IP-адрес, раскомментируйте строки **NODENAME** и **NODE_IP_ADDRESS**, удалив префикс «_#_», и замените значения параметров на выбранные вами. При необходимости вы можете изменить порт, раскомментировав параметр **NODE_PORT** и заменив номер порта на нужный. Однако я не рекомендую этого делать, если у вас нет других вариантов. Кроме этого, теперь вы можете сохранить и закрыть файл, не забыв перезапустить сервер RabbitMQ командой:

```bash
$ sudo systemctl restart rabbitmq-server
```

## Создание учётной записи администратора RabbitMQ

Для доступа к веб-интерфейсу RabbitMQ (о нём мы поговорим далее) вам нужна учётная запись администратора. Для этого можно использовать следующую команду, чтобы создать новую учётную запись администратора с полными правами на все vhost-сервера RabbitMQ:

```bash
$ sudo rabbitmqctl add_user rabbituser changeme
$ sudo rabbitmqctl set_user_tags rabbituser administrator
$ sudo rabbitmqctl set_permissions -p / rabbituser ".*" ".*" ".*"
```

Когда учётная запись администратора создана, для входа можно использовать следующие учётные данные:

  * **Имя пользователя**: _rabbituser_
  * **Пароль**: _changeme_

## Установка плагина управления RabbitMQ

RabbitMQ предлагает набор [плагинов от сообщества](https://www.rabbitmq.com/community-plugins) для расширения существующей функциональности. Нас особенно интересует плагин «_rabbitmq_management_», который предоставляет доступ к веб-интерфейсу, упрощающему мониторинг и настройку RabbitMQ.

Чтобы включить этот плагин, выполните следующую команду:

```bash
$ sudo rabbitmq-plugins enable rabbitmq_management
```

Это включит и другие необходимые плагины, такие как «_rabbitmq_management_», «_rabbitmq_management_agent_» и «_rabbitmq_web_dispatch_», которые вместе обеспечивают работу интерфейса управления RabbitMQ.

## Доступ к панели управления RabbitMQ

Наконец, чтобы получить доступ к веб-интерфейсу RabbitMQ, откройте ваш любимый браузер и перейдите по вашему внутреннему IP-адресу с портом **15672** (например: _http://ip-address:15672_). При первом посещении вы будете перенаправлены на страницу входа, где сможете использовать ранее созданные учётные данные администратора.

## Как удалить RabbitMQ в Linux

Чтобы удалить RabbitMQ из вашей системы Linux, сначала убедитесь, что вы удалили репозиторий зеркала Cloudsmith, если он использовался для установки. Для Debian, Ubuntu, Linux Mint и других родственных дистрибутивов используйте следующую команду:

```bash
$ rm /etc/apt/sources.list.d/rabbitmq-rabbitmq-erlang.list
$ apt-get clean
$ rm -rf /var/lib/apt/lists/*
$ apt update
```

Для Red Hat, Fedora, CentOS и других родственных дистрибутивов используйте эту команду:

```bash
$ rm /etc/yum.repos.d/rabbitmq-rabbitmq-erlang.repo
$ rm /etc/yum.repos.d/rabbitmq-rabbitmq-erlang-source.repo
```

После удаления репозитория можно удалить пакет сервера RabbitMQ соответствующей вашей дистрибутиву командой:

```bash
# На Debian, Ubuntu, Linux Mint или Kali Linux
$ sudo apt uninstall rabbitmq-server

# На Red Hat, Fedora, CentOS или AlmaLinux
$ sudo dnf uninstall rabbitmq-server
```
