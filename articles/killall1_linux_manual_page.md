# killall(1) — справочная страница Linux

Источник: [killall(1) — Linux manual page](https://man7.org/linux/man-pages/man1/killall.1.html)

KILLALL(1)                    Команды пользователя                    KILLALL(1)

## ИМЯ

```text
       killall - убивать процессы по имени
```

## ОБЗОР

```text
       **killall**[**-Z**, **--context** _шаблон_] [**-e**, **--exact**]
       [**-g**, **--process-group**] [**-i**, **--interactive**] [**-n**, **--ns** _PID_]
       [**-o**, **--older-than** _ВРЕМЯ_] [**-q**, **--quiet**] [**-r**, **--regexp**] [**-s**, **--signal**
       _СИГНАЛ_, **-**_СИГНАЛ_] [**-u**, **--user** _пользователь_] [**-v**, **--verbose**] [**-w**, **--wait**]
       [**-y**, **--younger-than** _ВРЕМЯ_] [**-I**, **--ignore-case**] [**-V**, **--version**] [**--**]
       _имя_ ...
       **killall -l**, **--list**
       **killall -V**, **--version**
```

## ОПИСАНИЕ

Команда **killall** отправляет сигнал всем процессам, выполняющим любую из указанных команд. Если имя сигнала не указано, отправляется SIGTERM.

Сигналы можно задавать либо по имени (например, **-HUP** или **-SIGHUP**), либо по номеру (например, **-1**), либо с помощью опции **-s**.

Если имя команды не является регулярным выражением (опция **-r**) и содержит косую черту (**/**), для уничтожения будут выбраны процессы, исполняющие этот конкретный файл, независимо от их имени.

**killall** возвращает нулевой код возврата, если по каждой из перечисленных команд был убит хотя бы один процесс, либо если команды не были перечислены, но хотя бы один процесс соответствует критериям поиска **-u** и **-Z**. В противном случае **killall** возвращает ненулевое значение.

Процесс **killall** никогда не убивает сам себя (но может убить другие процессы **killall**).

## ОПЦИИ

**-e**, **--exact**
       Требовать точного совпадения для очень длинных имён. Если имя команды длиннее 15 символов, полное имя может быть недоступно (т. е. оно выгружено из памяти — swapped out). В этом случае **killall** убьёт всё, что совпадает по первым 15 символам. С **-e** такие записи пропускаются. **killall** выводит сообщение о каждой пропущенной записи, если **-v** указана в дополнение к **-e**.

**-I**, **--ignore-case**
       Сравнивать имена процессов без учёта регистра.

**-g**, **--process-group**
       Убить группу процессов (process group), к которой принадлежит процесс. Сигнал отправляется группе только один раз, даже если найдено несколько процессов, принадлежащих одной группе процессов.

**-i**, **--interactive**
       Интерактивно запрашивать подтверждение перед уничтожением.

**-l**, **--list**
       Вывести список всех известных имён сигналов.

**-n**, **--ns**
       Сравнивать с PID-пространством имён (PID namespace) указанного PID. По умолчанию сравнение выполняется со всеми пространствами имён.

**-o**, **--older-than**
       Выбирать только процессы старше (запущенные ранее) указанного времени. Время задаётся числом с плавающей точкой, за которым следует единица измерения. Единицы: s, m, h, d, w, M, y — секунды, минуты, часы, дни, недели, месяцы и годы соответственно.

**-q**, **--quiet**
       Не жаловаться, если ни один процесс не был убит.

**-r**, **--regexp**
       Интерпретировать шаблон имени процесса как расширенное регулярное выражение POSIX, согласно [regex(3)](../man3/regex.3.html).

**-s**, **--signal**, **-**_СИГНАЛ_
       Отправить этот сигнал вместо SIGTERM.

**-u**, **--user**
       Убивать только процессы, принадлежащие указанному пользователю. Имена команд необязательны.

**-v**, **--verbose**
       Сообщать, был ли сигнал успешно отправлен.

**-V**, **--version**
       Показать информацию о версии.

**-w**, **--wait**
       Ждать, пока все убитые процессы не завершатся. **killall** раз в секунду проверяет, не существуют ли ещё какие-нибудь из убитых процессов, и возвращает управление, только когда не осталось ни одного. Учтите, что **killall** может ждать вечно, если сигнал был проигнорирован, не возымел действия или если процесс остаётся в состоянии зомби.

**-y**, **--younger-than**
       Выбирать только процессы моложе (запущенные позже) указанного времени. Время задаётся числом с плавающей точкой, за которым следует единица измерения. Единицы: s, m, h, d, w, M, y — секунды, минуты, часы, дни, недели, месяцы и годы соответственно.

**-Z**, **--context**
       Указать контекст безопасности (security context): убивать только процессы, чей контекст безопасности совпадает с данным шаблоном расширенного регулярного выражения. Должно предшествовать другим аргументам в командной строке. Имена команд необязательны.

## ИЗВЕСТНЫЕ НЕДОСТАТКИ

Уничтожение по файлу работает только для исполняемых файлов, которые остаются открытыми во время выполнения, т. е. «нечистые» (impure) исполняемые файлы нельзя убить таким способом.

Осторожно: ввод **killall** _имя_ может не дать желаемого эффекта в системах, отличных от Linux, особенно если это делает привилегированный пользователь.

**killall -w** не обнаруживает, если процесс исчез и между сканированиями был заменён новым процессом с тем же PID.

Если процессы меняют своё имя, **killall** может не суметь корректно сопоставить их.

**killall** имеет ограничение на количество имён, которые можно указать в командной строке. Это значение равно размеру беззнакового длинного целого (unsigned long), умноженному на 8. Для большинства 32-битных систем предел равен 32, аналогично для 64-битной системы предел обычно равен 64.
