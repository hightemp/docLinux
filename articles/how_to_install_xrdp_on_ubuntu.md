# Как установить Xrdp Server (удалённый рабочий стол) на Ubuntu 20.04

Источник: [How to Install Xrdp Server (Remote Desktop) on Ubuntu 20.04](https://linuxize.com/post/how-to-install-xrdp-on-ubuntu-20-04/)

Dejan Panovski · 22 мая 2020 · 4 мин

![](/images/d322db339b1aec58b032b6b296996ef6.png)

Xrdp — open-source-реализация протокола Microsoft Remote Desktop Protocol (RDP), позволяющая графически управлять удалённой системой. С RDP вы можете войти на удалённую машину и создать настоящий сеанс рабочего стола — точно так же, как если бы вы вошли на локальную машину.

Это руководство описывает установку и настройку Xrdp-сервера на Ubuntu 20.04.

## Установка окружения рабочего стола

Серверами Ubuntu управляют из командной строки, и окружение рабочего стола по умолчанию не установлено. Если у вас десктопная версия Ubuntu — пропустите этот шаг.

В репозиториях Ubuntu доступно множество окружений рабочего стола. Один вариант — установить Gnome, окружение по умолчанию в Ubuntu 20.04. Другой — [Xfce](https://xfce.org/): быстрое, стабильное и легковесное окружение, что делает его идеальным для удалённого сервера.

Выполните одну из команд ниже, чтобы установить выбранное окружение.

Установка Gnome:

```bash
sudo apt update
sudo apt install ubuntu-desktop
```

Установка Xfce:

```bash
sudo apt update
sudo apt install xubuntu-desktop
```

В зависимости от системы скачивание и установка GUI-пакетов займут какое-то время.

## Установка Xrdp

Xrdp включён в репозитории Ubuntu по умолчанию. Для установки выполните:

```bash
sudo apt install xrdp
```

После завершения установки служба Xrdp запустится автоматически. Проверить можно командой:

```bash
sudo systemctl status xrdp
```

Вывод будет выглядеть примерно так:

```text
● xrdp.service - xrdp daemon
     Loaded: loaded (/lib/systemd/system/xrdp.service; enabled; vendor preset: enabled)
     Active: active (running) since Fri 2020-05-22 17:36:16 UTC; 4min 41s ago
  ...
```

По умолчанию Xrdp использует файл `/etc/ssl/private/ssl-cert-snakeoil.key`, доступный для чтения только членам группы «ssl-cert». Выполните следующую команду, чтобы [добавить пользователя `xrdp` в группу](https://linuxize.com/post/how-to-add-user-to-group-in-linux/):

```bash
sudo adduser xrdp ssl-cert
```

Перезапустите службу Xrdp, чтобы изменения вступили в силу:

```bash
sudo systemctl restart xrdp
```

Готово. Xrdp установлен на вашем Ubuntu-сервере, и можно начинать пользоваться.

## Настройка Xrdp

Конфигурационные файлы Xrdp находятся в каталоге `/etc/xrdp`. Для базовых подключений менять конфигурацию не требуется.

Xrdp использует окружение рабочего стола X Window по умолчанию (Gnome или XFCE).

Главный конфигурационный файл — [`xrdp.ini`](https://github.com/neutrinolabs/xrdp/wiki/Configuration). Он разделён на секции и позволяет задавать глобальные параметры вроде безопасности и адресов прослушивания, а также создавать разные сеансы входа xrdp.

После любых изменений конфигурации нужно перезапустить службу Xrdp.

Xrdp использует файл `startwm.sh` для запуска X-сеанса. Если хотите использовать другое окружение X Window — отредактируйте этот файл.

## Настройка файрвола

Демон Xrdp слушает порт `3389` на всех интерфейсах. Если на вашем Ubuntu-сервере работает [файрвол](https://linuxize.com/post/how-to-setup-a-firewall-with-ufw-on-ubuntu-20-04/), нужно открыть порт Xrdp.

Чтобы разрешить доступ к серверу Xrdp с определённого IP-адреса или диапазона, например `192.168.33.0/24`, выполните:

```bash
sudo ufw allow from 192.168.33.0/24 to any port 3389
```

Если хотите разрешить доступ откуда угодно (настоятельно не рекомендуется по соображениям безопасности), выполните:

```bash
sudo ufw allow 3389
```

Для повышения безопасности можно настроить Xrdp на прослушивание только localhost и создать [SSH-туннель](https://linuxize.com/post/how-to-setup-ssh-tunneling/), безопасно переносящий трафик с вашей локальной машины с порта `3389` на тот же порт сервера.

## Подключение к серверу Xrdp

Теперь, когда сервер Xrdp настроен, откройте клиент Xrdp и подключитесь к серверу.

Если у вас ПК с Windows, можно использовать стандартный RDP-клиент. Введите «remote» в строке поиска Windows и нажмите «Remote Desktop Connection» — откроется RDP-клиент. В поле «Computer» введите IP-адрес удалённого сервера и нажмите «Connect».

![](/images/7b06d0f7a14f4ad6e8a32610ae540499.png)

На экране входа введите [имя пользователя](https://linuxize.com/post/how-to-add-and-delete-users-on-ubuntu-20-04/) и пароль и нажмите «OK».

![](/images/fefc3fbc45a3556a2e958e51648da414.png)

После входа вы увидите стандартный рабочий стол Gnome или Xfce. Выглядеть это будет примерно так:

![](/images/29b8b45b9fa4a81fa9492af1b096ea4d.png)

Теперь можно работать с удалённым рабочим столом с локальной машины, используя клавиатуру и мышь.

## Заключение

Мы показали установку и настройку Xrdp-сервера на Ubuntu 20.04. Теперь вы можете графически управлять своим сервером с локальной машины через RDP-клиент.
