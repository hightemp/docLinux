# Глава 20. Списки контроля доступа (ACL)

Источник: [Chapter 20. Access Control Lists](https://docs.redhat.com/en/documentation/red_hat_enterprise_linux/6/html/storage_administration_guide/ch-acls)

Руководство по администрированию хранения в Red Hat Enterprise Linux 6

У файлов и директорий есть наборы прав для владельца файла, группы, связанной с файлом, и всех остальных пользователей системы. Однако у этих наборов прав есть ограничения. Например, нельзя настроить разные права для разных пользователей. Поэтому были реализованы _списки контроля доступа_ (Access Control Lists, ACL).

Ядро Red Hat Enterprise Linux предоставляет поддержку ACL для файловой системы ext3 и экспортируемых по NFS файловых систем. ACL также распознаются на файловых системах ext3, доступ к которым осуществляется через Samba.

Помимо поддержки в ядре, для реализации ACL требуется пакет `acl`. Он содержит утилиты для добавления, изменения, удаления и получения информации ACL.

Команды `cp` и `mv` копируют или перемещают любые ACL, связанные с файлами и директориями.

## 20.1. Монтирование файловых систем

Перед использованием ACL для файла или директории раздел с этим файлом или директорией должен быть смонтирован с поддержкой ACL. Если это локальная файловая система ext3, её можно смонтировать следующей командой:

`mount -t ext3 -o acl _device-name_ _partition_`

Например:

`mount -t ext3 -o acl /dev/VolGroup00/LogVol02 /work`

Кроме того, если раздел указан в файле `/etc/fstab`, запись для раздела может включать опцию `acl`:

```text
LABEL=/work      /work       ext3    acl        1 2
```

Если доступ к файловой системе ext3 осуществляется через Samba и для неё включены ACL, то ACL распознаются, поскольку Samba собрана с опцией `--with-acl-support`. При доступе к разделяемому ресурсу Samba или его монтировании специальные флаги не требуются.

### 20.1.1. NFS

По умолчанию, если файловая система, экспортируемая NFS-сервером, поддерживает ACL и NFS-клиент может читать ACL, то клиентская система использует ACL. Чтобы отключить ACL на разделяемом ресурсе NFS при монтировании его на клиенте, смонтируйте его с опцией `noacl` в командной строке.
