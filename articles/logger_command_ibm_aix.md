# Команда logger (IBM AIX)

Источник: [logger Command](https://www.ibm.com/docs/en/aix/7.2?topic=l-logger-command)

Последнее обновление: 2026-08-15

## Назначение

Делает записи в системном журнале (system log).

## Синтаксис

```text
logger [ -f File ] [ -i ] [-r Count ] [ -p Priority ] [ -t Tag ] [ Message ]
```

## Описание

Команда **logger** предоставляет интерфейс к подпрограмме **syslog**, которая делает записи в системный журнал. Переменная _Message_ (сообщение) может быть указана в командной строке — она регистрируется немедленно, — либо читается переменная _File_ (файл), и каждая строка переменной _File_ регистрируется в журнале. Если вы не укажете ни флагей, ни переменных, команда **logger** будет ждать, пока вы введёте сообщение из стандартного ввода. Сообщения, возвращаемые средством **LOG_KERN**, не могут быть зарегистрированы этой командой.

## Флаги

| Элемент | Описание |
| --- | --- |
| **-f**_File_ | Регистрирует в журнале указанную переменную _File_ (файл). Если указана переменная _Message_, этот флаг игнорируется. |
| **-i** | Регистрирует идентификатор процесса (PID) процесса logger с каждой строкой. |
| **-p**_Priority_ | Вносит сообщение с указанным приоритетом. Параметр _Priority_ может быть числом или спецификатором приоритета вида _facility_**.**_level_. |
| **-t**_Tag_ | Помечает каждую строку в журнале указанным параметром _Tag_ (тег). |
| _Message_ | Указывает сообщение для регистрации. Если эта переменная не указана, команда **logger** регистрирует либо стандартный ввод, либо файл, указанный с флагом **-f**_File_. |
| **-r**_Count_ | Если ресурс буфера недоступен, повторяет попытки регистрации сообщения указанное количество раз. Если число не указано, повторяет попытки регистрации сообщения, пока оно не будет зарегистрировано. Число должно быть положительным целым в диапазоне от 1 до 1000. |

## Примеры

1. Чтобы зарегистрировать в журнале сообщение о перезагрузке системы, введите:

```bash
logger System rebooted
```

2. Чтобы зарегистрировать сообщение, содержащееся в файле /tmp/msg1, введите:

```bash
logger -f /tmp/msg1
```

3. Чтобы регистрировать критические сообщения (critical level) средства daemon, введите:

```bash
logger -pdaemon.crit
```

## Статус выхода

Эта команда возвращает следующие значения выхода:

| Элемент | Описание |
| --- | --- |
| **0** | Успешное завершение. |
| **>0** | Произошла ошибка. |
