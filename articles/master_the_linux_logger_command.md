# Команда logger в Linux: подробное руководство

Источник: [Master the Linux ‘logger’ Command: A Comprehensive Guide](https://hopeness.medium.com/master-the-linux-logger-command-a-comprehensive-guide-7743265e1ae1)

Peter Hou · 3 мин · 26 мая 2023

> В этой статье — подробное руководство по команде `logger` в Linux: её история, использование, распространённые параметры и малоизвестные приёмы. `logger` — ценный инструмент системного администратора, позволяющий добавлять записи в системные файлы журналов. Руководство включает примеры и типовые сценарии использования.

## О команде

Команда `logger` много лет является частью Unix-подобных операционных систем. Она была создана, чтобы предоставить простой интерфейс командной строки к модулю системного журнала syslog.

`logger` используется, когда нужно добавить записи в системные файлы журналов. Это полезно для отслеживания системных событий и отладки. Команда особенно удобна в скриптах: она позволяет скриптам записывать события или ошибки в системные журналы.

## Использование

Базовый синтаксис команды: `logger [опции] [сообщение]`. Если сообщение не указано, оно читается из стандартного ввода.

```bash
$ logger "This is a test log entry"
```

## Распространённые параметры

У команды `logger` несколько полезных параметров:

  * `-p, --priority priority` — задать приоритет сообщения. Приоритет указывается как уровень facility, за которым следует уровень severity. Например, 'auth.alert'.

```bash
$ logger -p auth.alert "This is a test log entry"
```

  * `-t, --tag tag` — пометить каждую строку журнала указанным тегом.

```bash
$ logger -t MYTAG "This is a test log entry"
```

## Другие поддерживаемые параметры

  * `-s, --stderr` — вывести сообщение в стандартный поток ошибок в дополнение к системному журналу.
  * `-u, --socket socket` — записать сообщение в указанный сокет вместо системного журнала.
  * `-f, --file file` — записать в журнал содержимое указанного файла.

## Типовые сценарии использования

Один из самых частых сценариев — использование `logger` в скриптах. С его помощью можно логировать начало и конец выполнения скрипта, а также возникающие ошибки:

```bash
$ logger "Starting script execution"
$ logger "Script execution completed"
```

## Малоизвестные приёмы

Хотя `logger` — довольно простая команда, есть один менее известный приём: она может логировать вывод других команд. Для этого вывод команды передаётся в `logger` по конвейеру:

```bash
$ echo "This is a test log entry" | logger
```

## На что обратить внимание

При работе с `logger` важно помнить, что системные файлы журналов обычно доступны для записи только пользователю root. Поэтому с командой `logger` может понадобиться `sudo`.

## Заключение

Команда `logger` — мощный инструмент добавления записей в системные журналы. Она особенно полезна в скриптах, позволяя логировать события и ошибки. Это относительно простая, но важная часть арсенала системного администратора.
