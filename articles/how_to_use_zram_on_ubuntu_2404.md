## Что такое ZRAM?

ZRAM — это модуль ядра Linux. Он создаёт сжатое блочное устройство в RAM. Это блочное устройство можно использовать как область подкачки (swap) или как временную файловую систему. Поскольку данные сжимаются, это экономит память и может ускорить систему.

## Плюсы и минусы использования ZRAM

**Плюсы:**

  1. **Более быстрый swap**: ZRAM значительно быстрее традиционной подкачки на жёстком диске.
  2. **Лучшая производительность**: может повысить производительность, снижая ввод-вывод на медленных дисках.
  3. **Более эффективное использование памяти**: данные сжимаются, поэтому в RAM помещается больше.

**Минусы:**

  1. **Нагрузка на CPU**: сжатие и распаковка потребляют ресурсы процессора.
  2. **Ограниченный объём**: размер ZRAM ограничен объёмом имеющейся RAM.

## Как использовать ZRAM в Ubuntu 24.04

  1. **Установите инструменты ZRAM**:

Откройте терминал и введите:

```bash
sudo apt update
sudo apt install zram-tools
```

  2. **Настройте ZRAM**:

Создайте или отредактируйте конфигурационный файл:

```bash
sudo nano /etc/default/zramswap
```

Добавьте или измените следующие строки:

```text
ENABLED=true
ALGO=zstd
PERCENTAGE=50
PRIORITY=100
```

Здесь `PERCENTAGE=50` означает, что ZRAM будет использовать 50% всей вашей RAM.

  3. **Включите ZRAM**:

Запустите и включите службу ZRAM:

```bash
sudo systemctl enable zramswap
sudo systemctl start zramswap
```

  4. **Проверьте ZRAM**:

Убедитесь, что ZRAM работает:

```bash
sudo zramctl
```

Вы должны увидеть вывод с информацией об устройствах ZRAM.

## Сколько RAM выделять под ZRAM

Использовать 50% RAM под ZRAM — хорошая отправная точка. Это хорошо работает для большинства систем. Если у вас 8 ГБ RAM, ZRAM займёт 4 ГБ. Корректируйте процент под свои нужды: если система часто исчерпывает память, можно увеличить процент; если CPU слабый — уменьшите, чтобы снизить нагрузку.

## Итог

ZRAM может ускорить ваш сервер Ubuntu, используя сжатое пространство подкачки в RAM. Его легко настроить, и он может улучшить производительность, особенно на системах с ограниченной памятью или медленными дисками. Начните с 50% RAM под ZRAM и корректируйте по мере необходимости.
